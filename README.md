# Zomato Restaurant Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Zomato Restaurant Dataset using Python. The analysis focuses on restaurant trends, ratings, cuisines, online delivery services, and customer preferences.

---

## Dataset Information
- Dataset: Zomato Restaurant Dataset
- Total Rows: 9551
- Total Columns: 21

---

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Steps Performed
1. Data Loading
2. Data Inspection
3. Data Cleaning
4. Missing Value Handling
5. Exploratory Data Analysis
6. Data Visualization
7. Insights Report

---

## Visualizations Included
- Bar Chart
- Pie Chart
- Scatter Plot
- Histogram
- Heatmap
- Line Chart

---

## Key Insights
1. New Delhi has the highest number of restaurants.
2. Most restaurants have ratings between 3 and 4.5.
3. Many restaurants do not provide online delivery.
4. Restaurants with more votes generally have higher ratings.
5. Restaurant ratings vary across price ranges.

---

## Conclusion
This project demonstrates how data analysis techniques can be used to identify restaurant trends, customer behavior, and business opportunities using real-world datasets.
