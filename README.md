# zomato-data-analysis
Project Overview

This project performs Exploratory Data Analysis (EDA) on the Zomato Restaurant Dataset using Python. The analysis focuses on restaurant distribution, ratings, online delivery availability, cuisines, and customer engagement.

Key Insights
New Delhi has the highest number of restaurants.
Most restaurants have ratings between 3 and 4.5.
Online delivery is unavailable in many restaurants.
Restaurants with more votes generally have better ratings.
Price range influences customer ratings.
